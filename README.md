# # Connect & Thrive – Young Adult Community Connection

## Project Overview

Connect & Thrive is a community web application designed to help young adults ages 20–35 build meaningful friendships through shared interests, wholesome activities, and community service.

Inspired by Christian values of kindness, inclusion, respect, and service, the application encourages positive social connections and a sense of belonging. Connect & Thrive is a friendship-building platform, not a dating application.

## Core Features

- **User Accounts and Profiles:** Register, log in, and manage personal interests.
- **Activity Listings and Search:** Browse activities by category, date, city, or country.
- **Activity Management:** Create, edit, and cancel community activities.
- **RSVP and Participation:** Register for activities and manage attendance.
- **Favorites:** Save interesting activities for future reference.

## Planned Technology

- **Frontend:** React or Next.js
- **Backend:** JavaScript or TypeScript
- **Database:** PostgreSQL or SQLite
- **Version Control:** Git and GitHub
- **Deployment:** Cloud hosting platform to be determined

The final technology stack will be selected collaboratively by the development team.
